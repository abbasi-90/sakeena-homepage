# Sakeena Homepage Mockup

Homepage concept for Sakeena (meetsakeena.com), a free matchmaking site for Muslim college students.

Built from the client brief: natural colors only (cream, sand, gold, terracotta, deep warm brown), no green, no teal, no crescent moon. Hero with the man on the left and the woman in a beige hijab on the right, label and Free badge in the empty middle.

Mockup only, not the live site. Includes a robots noindex, nofollow tag.
